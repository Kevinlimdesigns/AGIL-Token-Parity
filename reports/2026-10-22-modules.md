# Module-by-module token parity — 2026-10-22

This report compares each web dashboard module with its mobile counterpart: which tokens they share, and which appear on only one side. The scan was read-only.

**What is compared.** Only each module's own content:
- On web, the dashboard header and panel tabs are excluded. The map pins are excluded too, except on Map and Geofence.
- On mobile, the status bar, PTT bar, tab bar, nav bar and keyboard are excluded.
- Annotations are excluded on both.

**How the scores work.** Each score is the overlap in token usage. 100% means the same tokens used in the same proportions. Tokens under 0.25% of a module's usage count as noise. Control-size tokens are left out of the spacing score because touch targets are meant to differ.
- Raw data: `inventory/profiles/2026-10-22-content-profiles.json`.
- Machine-readable results: `reports/2026-10-22-modules.json`.

## Patterns across every module

1. **Matching everywhere:** body text (`text`, `text-muted`, `text-placeholder`), icons (`icon`, `icon-muted`), the main surfaces (`bg`, `bg-elevated`, `bg-subtle`), `border`, and `bg-primary`/`text-onColor` on primary buttons. The base layer is consistent.
2. **Links and selection:** mobile uses `color-*-interactive` in every module. Web uses it almost nowhere and seems to use `text-primary` / `border-primary` instead. That is inferred from usage; confirm on one component pair. *(PAR-003)*
3. **Status colours:**
   - Mobile uses its local `priority level/*` tokens and almost no AOH warning or info tokens.
   - Web uses AOH `icon-warning`, `icon-info`, `bg-info-strong` and the `warning-muted` family.
   - Info states appear almost only on web. Mobile has a few `bg-info-muted` / `bg-info-strong` uses, below the noise threshold. *(PAR-001)*
4. **Inverse colours** (`icon-invers`, `text-inverse`, `bg-invers`): web only, on the map and in chips. *(PAR-010)*
5. **Text styles differ the most** (14–61% match):
   - Mobile reads one step larger (`text-sm`/`text-base`, `semiBold`/`bold`) and uses `ShadCN h1/h2` for titles.
   - Web uses `text-xs`/`text-sm` and `medium`, with `text-lg/bold` for panel titles.
   - Some of this is expected for the platform. Titles need a decision. *(PAR-014)*
6. **Card corners:** mobile uses `radius-dialog` (8px); web uses `radius`, `radius-iconButton` and `radius-card` (12px). *(PAR-005)*
7. **Shared AOH components:** few. Only `Button`, `Icon Button` and `Input field` appear on both sides. Everything else is a separate local component on each platform.
